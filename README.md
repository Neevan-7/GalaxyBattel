# 🚀 GalaxyBattle – 2D Space Shooter Game

**GalaxyBattle** is a 2D sci-fi space shooter game developed using Unity. Take control of a powerful spaceship, fight waves of enemies, collect rewards, unlock ships, and survive endless space battles!

## 🎮 Game Overview

GalaxyBattle is an action-packed space combat game where players control a spaceship, shoot enemies, collect coins and crystals, and improve their combat abilities. The game features a space-themed environment with progressively challenging enemy waves.

## ✨ Features

- 🚀 **Player Ship Controls** – Control your spaceship during combat.
- 🔫 **Laser Shooting** – Aim and shoot enemies using the mouse.
- 👾 **Enemy Waves** – Fight enemies across increasingly challenging waves.
- 💥 **Combat Effects** – Visual effects for enemy destruction and explosions.
- ❤️ **Health System** – Monitor player health and survive enemy attacks.
- 🪙 **Coin Collection** – Earn coins by defeating enemies and collecting rewards.
- 💎 **Crystal Pickups** – Collect crystals during gameplay.
- 🛸 **Ship Shop** – Browse, unlock, and equip different spaceships.
- ⚡ **Special Skills** – Expand combat abilities with powerful upgrades.
- 🏆 **Score System** – Track your score and defeated enemies.
- ⏸️ **Pause Menu** – Pause and resume gameplay.
- ⚙️ **Settings Menu** – Configure game audio and other available settings.
- 🌌 **Space Environment** – Enjoy a sci-fi atmosphere with an infinite-style galaxy background.
- 🖥️ **PC and Mobile Targeting** – Designed with PC and mobile platforms in mind.

## 🛠️ Built With

- **Game Engine:** Unity 6
- **Programming Language:** C#
- **UI System:** Unity UI (UGUI)
- **UI Text:** TextMeshPro
- **Version Control:** Git and GitHub
- **Target Platforms:** PC and Mobile
- **Web Version:** Unity WebGL, if enabled in the build

## 🎯 How to Play

1. Launch the game.
2. Start a new mission.
3. Move your spaceship and aim at enemies.
4. Shoot enemies and avoid incoming attacks.
5. Defeat enemies to earn rewards and increase your score.
6. Collect coins and crystals.
7. Visit the ship shop to unlock or equip available ships.
8. Survive as many enemy waves as possible!

*Controls may vary depending on the platform and the current game build.*

## 🎮 Controls

| Action | Control |
|---|---|
| Aim | Mouse |
| Shoot | Mouse / configured shooting key |
| Pause | Pause button in the game UI |
| Navigate menus | Mouse / touch |

## 💻 Run the Project Locally

### Prerequisites

- Unity Hub
- A compatible Unity 6 Editor installation
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/GalaxyBattle.git
   ```

2. Open Unity Hub.
3. Select **Add Project from Disk**.
4. Choose the cloned `GalaxyBattle` folder.
5. Open the project using the compatible Unity Editor version.
6. Open the main game scene.
7. Press **Play** to start the game.

**Note:** Replace `YOUR-USERNAME` with your GitHub username. Ensure the required assets and scenes are included in the repository.
